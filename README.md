# tose-200
The Tose 200 ABC Collection

**John Tose** is a Welsh pibgorn maker and performer, arranger of the legendary "Tose 200" collection of 200 pibgorn tunes in ABC format. 

For the longest time was publicly hosted on the Moch Pryderi www.mochpryderi.com website, but as you can see that site is now defunct. As of now, I can't find any other copies of it online, so to avoid this collection being lost I'll keep it in this github repository, and on my own website at www.the-athenaion.com/tools_tose200
